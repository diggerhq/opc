# opc

`opc` is a terminal client for your organization's Computer, and the streaming API it is built on.

This repository starts with the documentation: the user-facing surface of `opc` and the Computer API, written out in full before the code, to find the inconsistencies in the design. The design itself is `serverless-agents-ws/.agents/work/084-computer-terminal-and-streaming-api.md`.

## Docs

The docs are a [Mintlify](https://mintlify.com) site in `docs/`. To preview them:

```bash
cd docs
npx mint dev
```
