<Update label="Unreleased" description="opc 0.1.0 · protocol opc.v1">
  First release.

  - `opc`, `opc -p`, `new`, `a`, `ls`, `log`, `send`, `wait`, `watch`, `interrupt`, `ask`, `subagents`, `rename`, `archive`, `unarchive`, `open`, `diff`, `push`, `pull`, `shell`, `login`, `logout`, `whoami`, `doctor`, `completion`, `config`.
  - The session API over HTTP and the `opc.v1` WebSocket protocol.
  - [Telemetry](/reference/telemetry): timings and error classes, never content, sent on the session's connection. Off with `OPC_TELEMETRY=0` or `opc config telemetry off`.
</Update>
