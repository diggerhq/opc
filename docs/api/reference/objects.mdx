---
title: "Objects"
description: "Session, Turn, Ask, Actor and Capabilities: the shapes every response and event uses."
---

The same objects appear in HTTP responses, WebSocket results and event data, byte for byte. Field names are camelCase. Times are ISO 8601 strings in UTC with milliseconds. Fields that do not apply are `null`, not absent, except where a field is marked optional.

New fields may appear in any object at any time. Ignore the ones you do not know.

## Session

```json
{
  "id": "cs_7f3a9k2m4q8r1t6v",
  "title": "flaky test in segment.test.ts",
  "status": "running",
  "owner": { "id": "usr_2k9d8f7a", "name": "Igor Zalutski", "email": "igor@acme.dev" },
  "origin": { "type": "api", "client": "opc/0.1.0", "slack": null },
  "settings": { "model": "claude-opus-5-5", "effort": "high", "mode": "acceptEdits" },
  "capabilities": { "…": "see below" },
  "activeTurnId": "tn_4m8q2x7c1v9b",
  "queued": [{ "turnId": "tn_9x2c7v1b4m8q", "input": "then update the changelog", "author": { "…": "Actor" } }],
  "asks": [],
  "lastTurn": { "id": "tn_1b4m8q9x2c7v", "status": "completed", "endedAt": "2026-10-26T09:12:44.120Z", "text": "Done. The PR is #482.", "error": null, "reason": null },
  "lastText": "I'll start by running the test a few times",
  "context": { "usedTokens": 41250, "windowTokens": 200000 },
  "lastSeq": 1184,
  "createdAt": "2026-10-26T09:01:02.311Z",
  "lastActiveAt": "2026-10-26T09:14:51.007Z",
  "urls": {
    "dashboard": "https://app.opencomputer.dev/computer/sessions/cs_7f3a9k2m4q8r1t6v",
    "slack": null
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | `cs_` followed by 16 lowercase letters and digits. Stable for the session's life. |
| `title` | string | From the first message until someone sets it. Up to 200 characters. |
| `status` | string | `starting`, `running`, `waiting`, `idle` or `suspended`. See [Concepts](/concepts#status). |
| `owner` | [Person](#person) | Who started the session. The agent acts as this person. |
| `origin` | object | Where the session started. `type` is `slack` or `api`. `client` is the creating client's name and version, from its `User-Agent`. `slack` is `{ teamId, channelId, channelName, threadTs, url }` for sessions started in Slack, else `null`. |
| `settings` | object | `model` and `effort` for the next turn, and the permission `mode` in force now |
| `capabilities` | [Capabilities](#capabilities) | What this session supports and allows |
| `activeTurnId` | string or null | The running turn |
| `queued` | array | Turns waiting to run, in order: `{ turnId, input, author }` |
| `asks` | array of [Ask](#ask) | Open asks, oldest first. Empty unless `status` is `waiting`. |
| `lastTurn` | object or null | The most recent turn that ended: `{ id, status, endedAt, text, error, reason }`. `text` is its last agent message. `error` is a [turn failure](/api/reference/errors#turn-failures) when `status` is `failed`. `reason` is set when `status` is `cancelled`. |
| `lastText` | string or null | The first 200 characters of the last message the agent wrote, for lists |
| `context` | object | `usedTokens` of `windowTokens` in the model's context window, as of the last model call |
| `lastSeq` | integer | The `seq` of the newest event. `0` for a session with no events yet. |
| `createdAt`, `lastActiveAt` | string | Creation, and the newest event |
| `urls` | object | `dashboard`, and `slack` for sessions started in Slack |

## Turn

```json
{
  "id": "tn_4m8q2x7c1v9b",
  "sessionId": "cs_7f3a9k2m4q8r1t6v",
  "status": "running",
  "mode": "queue",
  "input": "fix the flaky test in segment.test.ts and open a PR",
  "author": { "id": "usr_2k9d8f7a", "name": "Igor Zalutski", "via": "opc", "client": "opc/0.1.0" },
  "steering": [],
  "createdAt": "2026-10-26T09:01:02.400Z",
  "startedAt": "2026-10-26T09:01:02.415Z",
  "endedAt": null,
  "text": null,
  "error": null,
  "reason": null,
  "usage": null
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | `tn_` followed by 12 lowercase letters and digits |
| `status` | string | `queued`, `running`, `cancelling`, `completed`, `failed` or `cancelled`. `cancelling` is a running turn that has been [interrupted](/api/http/control#interrupt) and has not stopped yet. |
| `mode` | string | How it was sent: `queue`, `steer` or `interrupt` |
| `input` | string | The message, exactly as sent |
| `author` | [Actor](#actor) | Who sent it |
| `steering` | array | Messages steered into this turn while it ran: `{ input, author, at }` |
| `text` | string or null | The agent's last message, once the turn completed |
| `error` | object or null | A [turn failure](/api/reference/errors#turn-failures) when `failed` |
| `reason` | string or null | When `cancelled`: `interrupted` |
| `forced` | boolean or null | When `cancelled`: `true` if the agent process had to be restarted to stop it |
| `usage` | object or null | When ended: `{ inputTokens, outputTokens, reasoningTokens, cachedTokens, cacheWriteTokens, costUsd }`, summed over the turn's model calls. `costUsd` is `null` when your organization uses its own model account. |

A message sent with `steer` while a turn runs joins that turn: it has no turn of its own, and appears in the running turn's `steering`.

## Ask

Every ask has these fields, and more by `kind`:

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | `ak_` followed by 12 lowercase letters and digits |
| `kind` | string | `approval`, `question` or `secret` |
| `turnId` | string | The turn that raised it |
| `status` | string | `open`, `answered`, `dismissed` or `interrupted` |
| `createdAt` | string | |
| `closedAt` | string or null | |
| `closedBy` | [Actor](#actor) or null | Who answered or dismissed it. `null` when `interrupted`. |
| `answer` | object or null | The answer, in the shape for its kind |

### approval

```json
{
  "id": "ak_7c1v9b4m8q2x",
  "kind": "approval",
  "turnId": "tn_4m8q2x7c1v9b",
  "status": "open",
  "tool": { "name": "Bash", "callId": "toolu_01AbC", "input": { "command": "terraform apply -auto-approve", "cwd": "infra/staging" } },
  "title": "Bash: terraform apply -auto-approve",
  "always": "Allow every terraform command in this session",
  "createdAt": "2026-10-26T09:05:11.002Z",
  "closedAt": null, "closedBy": null, "answer": null
}
```

`tool` is the call waiting for approval, with its full input. `title` is one line for display. `always` describes what answering `always` would allow, or is `null` when this call cannot be allowed for the session. For a plan in `plan` mode, `tool.name` is `ExitPlanMode` and `tool.input.plan` is the plan.

Answer: `{ "decision": "allow" | "deny" | "always", "message": "optional, read by the agent" }`.

### question

```json
{
  "id": "ak_2x7c1v9b4m8q",
  "kind": "question",
  "turnId": "tn_4m8q2x7c1v9b",
  "status": "open",
  "questions": [
    {
      "id": "q1",
      "header": "Fix",
      "text": "Which fix do you want?",
      "multiSelect": false,
      "options": [
        { "label": "Make the test wait for the debounce", "description": "Smallest change; recommended" },
        { "label": "Make flush() await pending timers", "description": "Changes behaviour for callers" }
      ]
    }
  ],
  "createdAt": "2026-10-26T09:06:40.551Z",
  "closedAt": null, "closedBy": null, "answer": null
}
```

Answer: `{ "answers": [{ "questionId": "q1", "choices": ["Make the test wait for the debounce"], "text": null }] }`. `choices` are option labels. `text` is a free-text answer, with or without choices. Every question needs an answer with at least one choice or a text.

### secret

```json
{
  "id": "ak_9b4m8q2x7c1v",
  "kind": "secret",
  "turnId": "tn_4m8q2x7c1v9b",
  "status": "open",
  "name": "STRIPE_API_KEY",
  "reason": "To run the billing integration tests against Stripe's test mode.",
  "file": false,
  "createdAt": "2026-10-26T09:07:02.118Z",
  "closedAt": null, "closedBy": null, "answer": null
}
```

A secret ask is answered by [setting the secret](/api/http/secrets), never through the ask: the value must not enter the session's history. Setting a secret with this `name` that reaches this session answers the ask, and `answer` becomes `{ "scope": "session" }`. `file: true` means the agent wants the value as a file.

## Actor

Who did something, in turns, asks and events.

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | The person's id, `usr_…` |
| `name` | string | Display name |
| `via` | string | `slack`, `opc`, `dashboard` or `api` |
| `client` | string, optional | The client's name and version, for `opc` and `api` |

`via` and `client` come from the credential and the request, never from the request body. A client cannot claim to be someone else.

## Person

`{ id, name, email }`. `email` is `null` when your organization hides it.

## Capabilities

```json
{
  "models": [
    { "id": "claude-opus-5-5", "name": "Opus 5.5", "efforts": ["low", "medium", "high", "xhigh", "max"], "contextWindow": 200000, "default": true },
    { "id": "claude-sonnet-5-5", "name": "Sonnet 5.5", "efforts": ["low", "medium", "high"], "contextWindow": 200000, "default": false }
  ],
  "modes": ["default", "acceptEdits", "plan", "auto", "dontAsk"],
  "features": { "steer": true, "compact": true, "shell": true, "workspace": true, "reasoning": true, "subagents": true }
}
```

| Field | Meaning |
| --- | --- |
| `models` | Models this session may use, as your organization allows. `efforts` lists the levels each accepts. |
| `modes` | Permission modes this session may use. `bypassPermissions` appears only when your organization allows it. |
| `features` | What this session supports. A client hides what is `false`. `steer`: messages mid-turn; `compact`; `shell`; `workspace`: files; `reasoning`: the model's reasoning is streamed; `subagents`: `parentCallId` can be set. |

Capabilities are per session, not per release: check them instead of the API version. They change only when your organization's settings change.
