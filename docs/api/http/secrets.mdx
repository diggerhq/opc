---
title: "Secrets"
description: "Organization secrets and variables: set, replace, delete, list and history. Values go in and never come out."
---

A secret is an environment variable every session on the computer gets: an API key, a token, or a file such as a service-account JSON (then `$NAME` holds the file's path). A **variable** is the same, but not secret: its value is listed, and sessions do not redact it from their output.

This API manages the **organization** layer: secrets every session in the organization gets. For now that means sessions started in Slack; sessions started from the dashboard or this API do not get secrets yet. Personal ("Just me") and thread secrets are set in Slack for now; when a session has one of the same name, it wins over the organization's.

<Warning>
Every session on the organization's computer can read every secret delivered to the computer, not only its own. Store only what anyone who can run a session may use.
</Warning>

## Who can

- **Any member** of the organization can list, set, replace and delete organization secrets.
- Listing and history need `sessions:read`. Setting and deleting need `secrets:write`, which a key has only when it was created naming it: a key with every scope (`*` or `sandbox:*`) does not get it. Signed in to the dashboard, you have it.
- **Sessions cannot.** The short-lived key a session gets on the computer is refused on every route here with `403 forbidden`, `"reason": "computer_principal"`, whatever its scopes.

## Set or replace

```http
PUT /organization/secrets/{name}
```

```bash
curl -s -X PUT "$API/organization/secrets/EXECUTOR_API_KEY" -H "x-api-key: $OPENCOMPUTER_API_KEY" \
  -H "content-type: application/json" --data @- <<< "{\"value\": \"$EXECUTOR_API_KEY\"}"
```

| Field | Meaning |
| --- | --- |
| `value` | The value, a non-empty string of at most 64 KB (`413 too_large` over it). |
| `file` | Optional. `true`: sessions get a file holding the value, and `$NAME` is its path. Default `false`. |
| `variable` | Optional. `true`: a variable, listed with its value and never redacted. Cannot be a file. Default `false`. |

`201` with the new [secret](#the-secret-object), or `200` when it replaced one. Running sessions get the change from their next command on.

A name is letters, digits and `_`, not starting with a digit, at most 64 characters. Names that would change how a session runs or where its tools fetch from are refused with `400 invalid_name`: `PATH`, `HOME`, `NODE_OPTIONS`, `LD_*`, `GIT_*`, `CLAUDE*`, `ANTHROPIC_*`, `SP_*`, proxies and CA bundles, `XDG_*`, `NPM_CONFIG_*`, `PIP_INDEX_URL`, `UV_INDEX_URL`, `GOPROXY`, `DOCKER_HOST`, `JAVA_TOOL_OPTIONS` and a few more. A base URL (`*_BASE_URL`, `*_API_BASE`) can only be a variable, so everyone can see where it points.

## Delete

```http
DELETE /organization/secrets/{name}
```

`204`. `404 secret_not_found` when there is no organization secret of that name.

## List

```http
GET /secrets
```

```json
{
  "secrets": [
    {
      "name": "EXECUTOR_API_KEY",
      "layer": "organization",
      "kind": "secret",
      "file": false,
      "createdAt": "2026-10-29T14:02:11.000Z",
      "createdBy": { "slackUserId": "U07ABCDE" },
      "updatedAt": "2026-11-01T09:15:40.000Z",
      "updatedBy": { "member": "usr_01jabcdefghjkmnpqrstvwxyz0", "name": "Igor" },
      "lastUsedAt": "2026-11-01T09:20:03.000Z",
      "overriddenIn": { "threads": 2, "people": 1 }
    }
  ]
}
```

### The secret object

| Field | Meaning |
| --- | --- |
| `name` | The environment variable's name. |
| `layer` | `organization`. |
| `kind` | `secret` or `variable`. |
| `file` | Sessions get it as a file. |
| `value` | Variables only. A secret's value is never returned. |
| `createdBy`, `updatedBy` | `{ "member", "name" }` for the dashboard and this API, `{ "slackUserId" }` for Slack. |
| `lastUsedAt` | When a session last got it since it was set, to the minute, or `null`. |
| `overriddenIn` | How many Slack threads (`threads`) and people (`people`) have their own secret or variable of the same name, which wins over this one in their sessions. |

## History

```http
GET /secrets/{name}/events
```

The organization layer's changes to that name, newest first, at most 100, kept a year.

```json
{
  "events": [
    { "at": "2026-11-01T09:15:40.000Z", "action": "replace", "kind": "secret", "actor": { "member": "usr_01jabcdefghjkmnpqrstvwxyz0", "name": "Igor" }, "via": "dashboard" }
  ]
}
```

`action` is `set`, `replace` or `delete`. `via` is `slack`, `dashboard`, `api` or `opc`.

## Limits

- At most 200 organization secrets and variables together: `409 limit_reached`.
- At most 30 changes a minute per member: `429 rate_limited`, with `retryAfterMs`.
- `PUT` and `DELETE` on `/me/secrets/{name}` and `/sessions/{id}/secrets/{name}` answer `409 feature_unavailable` for now.
